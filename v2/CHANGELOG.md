# v2 변경 이력 (패치 버전별)

작성 규칙 (CLAUDE.md 작업 규칙 7)
- main에 병합될 때마다 버전을 하나 올린다.
- 버전 번호는 `MAJOR.MINOR.PATCH`로 쓴다.
  - 분류 결과나 사용 기능이 늘면 MINOR를 올린다.
  - 결과가 같은 수정·정리이면 PATCH를 올린다.
- 각 항목은 **무엇을 바꿨나 → 왜 바꿨나 → 측정 결과**를 함께 적는다.
- 자세한 설계 이유와 오류 분석은 작업 보고서(`WORK_REPORT_*.md`)에 둔다.
- 현재 버전은 `v2/VERSION`에 기록되고, 앱 제목 표시줄에 보인다.
