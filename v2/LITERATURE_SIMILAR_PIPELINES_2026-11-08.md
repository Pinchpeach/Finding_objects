# 비슷한 역할의 파이프라인과 비교 (2026-11-08)

사용자 요청: 비슷한 역할을 하는 파이프라인을 문헌·git 저장소에서 찾아 우리와 비교하고, 나은 점은 설계를 살펴 적용·실험한 뒤 유의미한 개선이면 선정 이유를 밝힌다.

## 1. 찾은 파이프라인

우리 파이프라인이 하는 일은 두 단계다.
- (가) 여러 파장 목록의 행을 한 천체로 묶는다(연관).
- (나) 묶인 근거로 별·은하·QSO와 세부 종류를 정한다(분류).

비슷한 일을 하는 공개 파이프라인:

| 파이프라인 | 하는 일 | 공개 코드 | 우리와 겹치는 단계 |
|---|---|---|---|
| **NWAY** (Salvato et al. 2018, MNRAS 473, 4937) | 여러 목록 동시 교차 일치. 위치 베이즈 인자 × 등급·색 사전확률, "짝 없음" 확률(p_any) | github JohannesBuchner/nway (PyPI `nway` 4.8.0, 원본 코드를 받아 읽음) | (가) |

  - 어두운 은하를 우리가 별로 부른 경우: 5–6개.

**이 차이를 우리에게 옮길 수 있나 (시험)**
- 같은 설계(PS1 grizy + psf−Kron + WISE, RF)를 세트 A가 아닌 SDSS 벤치마크 학습 분할로 학습했다(독립 검증을 지키기 위해).

## 4. 실험 2: NWAY 색 사전확률 (연관 단계)

**NWAY 설계 (원본 `nwaylib/magnitudeweights.py`를 읽고 확인)**
- secure 짝(사후확률 > 0.9)의 등급 분포 h_sel과 전체 분포 h_all을 secure 표본의 15개 분위로 나눈 칸에서 센다.
- 비율 h_sel/h_all을 배경 가중 평균이 1이 되게 정규화한다.
- 이 값을 위치 베이즈 인자에 곱한다.

**우리에게 옮긴 것 (`Preprocess/association_model.py`, 기본은 꺼짐: `V2_ASSOC_PHOT_PRIOR=1`)**
- 성질: 광학 앵커와의 색. AllWISE는 G − W1, 2MASS는 G − Ks.
- 표(`Preprocess/phot_prior.csv`, `benchmark/build_phot_prior.py`)는 세트 A blind 결과로 만들었다.
  - h_sel: 한 천체에 Gaia와 그 목록 행이 함께 있는 경우(AllWISE 128,552, 2MASS 137,329).
  - h_all: 6–30″ 떨어진 다른 천체의 G와 짝지은 우연한 쌍(373만, 1,125만).
- 표의 모양:
  - 진짜 WISE 짝은 G − W1이 1.5–4다(가중치 2.4–8.8).
  - 5.3보다 붉은 쌍은 가중치 0.13이다.
  - 2.47 검증의 J042925 경우(탄소별 WISE 원천이 4.8″ 떨어진 다른 Gaia 별에 붙음, G − W1 ≈ 11)가 이 칸이다.
- 가중치는 점수와 사후확률에 곱해진다. 곱한 점수가 수용 문턱(1e-5) 아래면 짝을 받지 않는다.

**시험 방법 (`.github/workflows/experiment-ab-fields.yml`, `benchmark/compare_ab_fields.py`)**
- 세트 B 26개 영역을 한 번만 수집하고, 같은 blind 원자료로 base와 phot를 각각 돌렸다.
- 정답 천체별로 고침과 깨짐을 비교했다.
- NWAY 방식대로 AllWISE·2MASS 위치를 2′ 옮긴 사본에서 받아들여진 짝 수(= 거짓 연관)도 세었다.

**결과** (26개 영역, `benchmark/experiments/assoc_phot_prior/`)

| | base | phot (NWAY 색 사전확률) |
|---|---|---|
| 정답 천체 정확도 (973개) | 99.589 % | 99.589 % (고침 0,깨짐 0) |
| 정답 옆 단일 목록 조각 | 270 | 262 |
| 천체 수 | 397,235 | 396,358 |
| AllWISE 행이 짝을 찾음 | 38,896 / 51,059 | 39,545 |
| 2′ 옮긴 AllWISE가 짝을 찾음 (거짓 연관) | 27,094 (53 %) | 27,072 |
| 2′ 옮긴 2MASS가 짝을 찾음 | 2,708 (12 %) | 2,563 (−5 %) |
| 연관 단계 시간 (중앙값) | 4.81 s | 4.84 s |

**판단**
- 분류 정확도 변화가 없다(고침 0 = 깨짐 0). 미리 정한 채택 기준(고침 > 깨짐, 그리고 거짓 연관 감소)을 넘지 못했다.
- 기본값으로 켜지 않고 선택 기능으로 둔다.
- 거짓 연관이 거의 줄지 않은 이유: NWAY 가중치는 전형적인 색(G − W1 1.5–4)의 짝을 최대 8.8배 올린다. 그래서 우연히 전형적인 색을 가진 가짜 짝도 함께 올라간다.

**더 큰 발견 (NWAY의 옮긴 목록 시험에서)**
- 위치를 2′ 옮긴 AllWISE 행의 절반 이상(53 %)이 엉뚱한 천체에 붙었다.
  - 고은위 성긴 영역: 29–35 %.
  - 구상성단·산개성단·장미성운: 88–94 % (실제 위치 87–94 %와 같음, 사실상 무작위).
- 원인: 우연 일치 확률과 사후확률에 **검출 자신의 목록 밀도**(WISE)를 쓰고 있었다.
  - Budavári & Szalay 2008과 NWAY는 **짝 후보 목록의 밀도**를 쓴다.
  - 6″ PSF의 AllWISE 행이 성긴 WISE 하늘 기준으로 판정되어, 4–5″ 거리의 광학 천체도 우연이 아니라고 보았다.
- 이를 고친 변형(`V2_ASSOC_CANDIDATE_DENSITY=1`)을 같은 방식으로 시험했다(5절).

## 5. 실험 3: 우연 일치를 짝 후보 목록의 밀도로 계산

**바꾼 것** (`Preprocess/01_source_association.py` `_pair_density`)
- 우연 일치 확률(1 − exp(−π r² ρ))과 사후확률의 배경 밀도 ρ에, 검출 목록과 짝 후보(앵커) 목록의 밀도 중 큰 값을 쓴다.
- 근거: Budavári & Szalay 2008. NWAY도 사전확률에 상대 목록의 밀도를 넣는다.
- 이전에는 검출 자신의 목록 밀도를 썼다. 그래서 6″ PSF의 AllWISE 행이 성긴 WISE 하늘 기준으로 판정되었다.

**결과** (같은 26개 영역, 같은 원자료, `benchmark/experiments/assoc_density/`)

| | base | phot | cand | **both (채택)** |
|---|---|---|---|---|
| 정답 천체 정확도 (973개) | 99.589 % | 99.589 % | 99.589 % | 99.589 % |
| 고침 / 깨짐 | – | 0 / 0 | 0 / 0 | 0 / 0 |
| 정답 옆 단일 목록 조각 | 272 | 264 | 275 | 267 |
| 옮긴 AllWISE의 거짓 연관 | 27,094 | 27,072 | 23,266 (−14 %) | **23,251 (−14 %)** |
| 옮긴 2MASS의 거짓 연관 | 2,708 | 2,563 | 2,119 (−22 %) | **2,049 (−24 %)** |
| 실제 AllWISE 짝 | 38,896 | 39,545 | 36,547 | 37,138 |
| 영역당 Stage 1–7 합 (중앙값) | 72.3 s | 72.2 s | 76.1 s | 75.6 s |
| 26개 영역 전체 합 | 2,102 s | 2,115 s | 2,134 s | 2,124 s (+1.0 %) |

(base 열의 조각 수는 같은 실행 안의 값이라 4절 실행과 2개 다르다. 실행마다 수집 결과가 조금 다르다.)

## 6. 선정과 이유

**채택: "both" (NWAY 색 사전확률 + 짝 후보 밀도), 2.48.0 기본값**
1. **방법의 오류를 바로잡는다.**
   - 이전 규칙은 우리가 인용한 방법(Budavári & Szalay 2008)과 달리 검출 자신의 목록 밀도를 썼다.
   - NWAY의 옮긴 목록 시험이 이것을 드러냈다(옮긴 AllWISE의 53 %가 엉뚱한 천체에 붙음).
2. **거짓 연관이 줄어든다.**
   - AllWISE −14 %, 2MASS −24 %.
   - 두 변화를 함께 쓸 때 2MASS가 가장 많이 줄고, 정답 옆 조각도 272 → 267로 준다. 짝 후보 밀도만 쓰면 조각이 275로 는다.
3. **잃는 것이 없다.**
   - 정답 천체 973개에서 고침 0, 깨짐 0.
   - 처리 시간: 26개 영역 전체 합은 +1.0 %, 영역당 중앙값은 +4.6 %(72.3 → 75.6 s)다. 연관 단계 자체는 +3 %(5.12 → 5.28 s)다.
4. **한계 (솔직히)**
   - 미리 정한 기준 "고침 > 깨짐"은 0 = 0으로 넘지 못했다. 정답 표본(밝은 분광 표적)은 연관 오류가 일어나는 어두운·혼잡한 경우를 거의 담지 않는다.
   - 채택 근거는 분류 정확도가 아니라 연관 품질(NWAY의 거짓 연관 측정)과 방법의 정합성이다.
   - 끄는 스위치를 남겼다: `V2_ASSOC_PHOT_PRIOR=0`, `V2_ASSOC_CANDIDATE_DENSITY=0`.
5. **남은 문제**
   - 옮긴 AllWISE의 46 %는 여전히 짝을 찾는다.
   - 받아들이는 반경(0.6 × PSF = 3.7″)과 위치 점수 문턱(1e-5)이 혼잡 영역에서 넓다.
   - NWAY처럼 거짓 연관률 목표(예: 5 %)로 p_any 문턱을 정하는 보정이 다음 단계다.

**채택하지 않음**
- Clarke+2020·Hughes+2022 식 단일 모형(3절): 우위가 같은 분포 정답 학습에서 온다. 벤치마크로 학습하면 영역에서 73 %에 그친다.
- UNKNOWN 대체 분류(3절): 같은 이유.
- MUWCLASS·Tranin(X선 원천 분류): 우리 X선 축은 이미 문헌 규칙을 쓰고, 그들의 학습 표본(X선 원천 수천 개)이 없다. 설계상 새로 옮길 부분이 없었다.
- ALeRCE 계층 RF: 우리 변광성 세부 종류는 2.47.0에서 Gaia DR3 분류기 이름을 그대로 쓴다. 광도곡선 특징 학습은 ZTF 경보 자료와 정답 표본이 필요해 이번 범위 밖이다.
