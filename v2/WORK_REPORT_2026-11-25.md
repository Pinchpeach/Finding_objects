# 작업 보고서 2026-11-25: Gaia DR4 전환 준비 (2.60.4, 과제 1)

계획 세션 지시서(2026-11-25 과제 1)에 따라 DR4 전환의 **준비**만 했다. DR4 자료는 보지 못했고(공개 2026-12-02), 전환과 짝 비교는 하지 않았다. DR3 결과는 같다.

## 1. 한 일과 결과
- 문서 둘: `GAIA_DR4_READINESS_2026-11-25.md`(의존 목록 42항목, 잠근 프로토콜, 코드 준비), `LITERATURE_GAIA_DR4_2026-11-25.md`(DR4 조사, 확인 수준 표시).
- DR4 데이터 모델 초안(ESA가 2026-06-26 공개한 ZIP의 PDF, 1,231쪽)을 내려받아 구문 분석했다: 표 141개, 열 4,629개(`benchmark/gaia_dr4/dr4_draft_tables.json`). DR3 수집기가 요청하는 64열 대조(`dr3_columns_vs_dr4_draft.csv`): 같은 표에 남는 것 35열(`gaia_source` 27 + `vari_summary` 8), **다른 표로 간 것 20열(천체물리)**, **초안에 없는 것 7열**.
- 코드: 제품 지도(`gaia_release.py`), 분류 상수 표(`Preprocess/gaia_assumptions.py`), `check_gaia_release.py` DR4 발견 모드, 시험 11개.
- DR3 동일성: 시험 + 같은 원자료 4곳 × 5개 파일을 2.60.3 코드와 모든 셀 비교(다른 셀 0).

## 2. 왜 이렇게 짰나
- **제품 지도.** 기존 `gaia_release.py`는 스키마 이름과 기준 시기만 가졌고 열 목록은 `gaia_dr3.py`의 상수였다. DR4는 천체물리 표가 4개로 나뉘고 열 일부가 없어서, DR3 목록을 DR4 표에 보내면 ADQL 오류다. 릴리스마다 `{제품 → (표, 열, 상태 열)}`를 갖게 하고 수집기는 그 지도를 순서대로 돌게 했다. DR3 지도는 옛 상수 그대로(열 목록 해시와 SQL 문자열을 시험이 묶음). DR4 지도는 **추측해 채우지 않고 `None`**으로 두었다: 초안은 초안일 뿐이라 아카이브 자신의 메타데이터를 읽은 뒤(`check_gaia_release.py`) 손으로 채운다. DR4를 고르면 DR3 사본으로 가서 DR3로 표시한다(아카이브가 죽었을 때와 같은 경로라 새 동작이 아니다).
- **분류 상수 표를 Preprocess 쪽에 따로.** 수집 쪽 `gaia_release.py`에 합치지 않았다: 단계 모듈들이 서로를 경로로 불러 쓰는 구조(Get_data와 Preprocess는 서로 import하지 않음)를 깨지 않기 위해서다. 두 표의 릴리스 이름이 같음은 시험이 확인한다. 릴리스는 환경 변수가 아니라 **데이터의 `gaia_release` 열**로 고른다: 저장된 DR3 원자료를 `V2_GAIA_RELEASE=DR4`인 환경에서 분류해도 DR3 값을 쓴다. 열이 없으면 DR3(보존된 특징, 옛 원자료).
- **DR4는 `LookupError`.** 값이 없는 릴리스의 행을 DR3 상수로 조용히 분류하면 영점이나 C* 판정이 틀려도 경고 없이 라벨이 바뀐다. 멈추는 편이 낫다.
- **`dataclass`에 `from __future__ import annotations`를 안 쓴 이유.** 단계 모듈들이 이 파일을 경로로 읽으면서 `sys.modules`에 등록하지 않아서, 문자열 주석의 dataclass가 `NoneType.__dict__` 오류를 냈다(시험 중 발견).
- **옮기지 않은 것.** `Classifier/branches/star.py`, `subclass.py`의 RUWE 1.4와 C* 식은 Classifier가 Preprocess를 경로로 읽지 않아 복사본이 남았다. 시험이 `star.py`의 식이 표의 DR3 값과 같음을 묶는다. 전환 때 같이 옮긴다.
- **대안으로 버린 것:** DR4 열 이름 대응을 지금 코드로 박는 것(초안에서 "같은 이름"인 열도 정의가 같다는 보장이 없고, 변광 분류기는 구조가 달라 대응이 설계 결정이다).

## 3. 확인하지 못한 것(미확인)
- DR3 표가 DR4 공개 뒤에도 같은 아카이브에서 제공되는지(어느 ESA 페이지에도 없음). DR4 TAP 스키마 이름. 시차 영점 레시피와 `ruwe`·오차의 DR4 정의(논문 목록에 있으나 arXiv 링크가 비어 있음). VizieR의 DR4 사본.
- DSC 논문(arXiv:2605.23388)과 FLAME 논문(arXiv:2607.00264)은 앞 40k자만 원문으로 읽었고 나머지는 요약이다. 해당 문장은 문서에 "요약만"으로 표시했다.
- 데이터 모델의 `tentative_parallax_bias`가 가리키는 참고문헌은 초안에서 `?`로 비어 있다.

## 4. 프로토콜의 숫자
채택 기준(정확도 차이 95 % 하한 ≥ −0.10 %p, 고신뢰 순도 84 % 하한 ≥ 0.98, 수집 시간 +20 % 이내 등)은 DR4 자료를 보기 전에 정한 **제안값**이다. 검토 세션이 바꾸려면 12-02 이전에 바꿔야 의미가 있다.
