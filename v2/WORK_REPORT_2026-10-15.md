## 2. 벤치마크 자료 오염과 복원
- **증상**: 같은 설정으로 다시 학습해도 DESI가 73–80 %로 떨어짐.
- **원인**:
  - 2.23.0의 코드 모양 정리(black)가 `v2/Get_data`와 벤치마크 스크립트를 바꿨다.
  - 그 경로를 트리거로 가진 워크플로들이 push마다 자동 실행되어, 보존 자료를 새로 수집한 자료로 덮어썼다(3202f3d, 7b39057 등).
  - DESI 정답은 VizieR 일부 실패 때문에 249개가 적은 부분 수집본이 되었다.
- **확인**: 2.22 코드(282017f)에 새 자료를 쓰면 DESI 77.6 %, 원래 자료를 쓰면 91.79 %였다. 원인은 코드가 아니라 자료다.
- **조치 1**: 282017f 이후 바뀐 벤치마크 자료(.py/.md 제외)를 모두 되돌렸다.
- **조치 2**: 자료를 커밋하는 워크플로 20개를 수동 실행 전용으로 바꿨다.
  - 2.6.4에서 `Build Catalog Truth Features`에만 적용한 원칙("보존 자료는 의도적으로만 바뀐다")을 나머지에도 적용한 것이다.
  - 자동 실행의 이점(코드 변경 즉시 재수집)보다, 외부 서비스의 일시 장애가 정답 세트를 조용히 바꾸는 위험이 크다.

## 3. 개선안 검증
### #1 상호작용 특징 (버림)
- **근거**: Assef et al. 2018 R75(W1−W2 > 0.486 Vega).
  - 숙주 은하가 보이는 AGN은 GALAXY 형태 증거를 갖지만, 중적외선 색은 은하와 밝은 AGN 사이에 놓인다.
  - 선형 융합은 "해상된 천체에서만 W1−W2를 더 크게 보는" 것을 표현할 수 없다. 그래서 곱 특징을 따로 만들었다.

| 시도 | SDSS | DESI | 문제 |
|---|---:|---:|---|
| 재학습만 (채택) | 97.84 | 91.89 | |
| 해상 × W1−W2 + 해상 표시 + GALEX FUV−NUV | 97.44 | 90.96 | "해상" 표시가 LS-MORPH-002와 겹쳐 부호 제약이 그 증거를 버림 → 별 15개가 QSO로 |
| 해상 × max(0, W1−W2 − R75) (표시 없음) | 97.64 | 90.96 | DSC-001:QSO, LS-CKNN-001:QSO가 부호 제약으로 빠져 사전 가중치로 돌아감 → DESI STAR 재현율 0.855 |

- **결정적 측정**: 재학습만 한 모델에서 아직 GALAXY로 가는 QSO(SDSS 17개, DESI 11개)의 R75 초과량 중앙값은 0이다. 초과량이 있는 해상 QSO는 이미 맞히고 있다.
- **결론**: 남은 오류는 중적외선으로 구별되지 않는다. 같은 구조의 다른 특징을 더해도 같은 결과가 예상되어 이 방향을 닫았다.

### #2 CatWISE 고유운동, GALEX (구현 안 함)
- DESI에서 STAR → QSO 11개, QSO → STAR 9개:

| 항목 | 값 |
|---|---|
| r 중앙값 | 21.0–21.6 |
| W1 중앙값 (Vega) | 17.5 (STAR → QSO), 17.8 (QSO → STAR) |
| Gaia 일치 | 18 % / 44 % |
| GALEX 검출 | 0 % / 11 % |

- **CatWISE2020**: 운동 정확도가 W1 ≈ 17에서 ~100 mas/yr이다(Marocco et al. 2021). 헤일로 별의 운동(5–20 mas/yr)을 잴 수 없다.
- **GALEX**: 대상 대부분이 검출되지 않는다. 비검출은 관측 영역 정보 없이 증거로 쓸 수 없다.
- 수집기·워크플로를 만들기 전에 측정으로 걸렀다. 몇 시간짜리 Actions 수집을 아꼈다.

### 재학습 자체의 이득
- 같은 명령(증강 3그룹)으로 복원된 자료에 다시 학습했다. 2.23 가중치보다 SDSS +0.25 pp, DESI +0.93 pp.
- 차이는 부호 제약으로 빠지는 키 하나(PS1-CKNN-001:STAR)와 그에 따른 재가중이다.
- NGC 4522 실제 영역(84개)의 결과는 같다.
- `Preprocess/README.md`의 재학습 명령이 증강 2그룹만 적고 있어 실제 설정(3그룹)으로 고쳤다.

## 4. 정밀도 판단 (2.24.0, test split)

| 세트 | 정확도 | 기권 | 주요 오류 |
|---|---:|---:|---|
| SDSS (1991) | 97.84 % | 0.6 % | QSO → GALAXY 20, STAR 기권 9, GALAXY → QSO 5 |
| DESI (962) | 91.89 % | 1.5 % | QSO → GALAXY 15, STAR → GALAXY 14 (r ≈ 22.5), GALAXY → QSO 12, STAR → QSO 11, QSO → STAR 9 |

- **비선형 융합(GBM, 측정만)**: 같은 증거로 학습하면 기권 없이 SDSS 98.09 %, DESI 92.93 %다.
  - 선형 모델을 비슷한 적용률(임계 0.5)로 맞추면 SDSS 97.6 %, DESI 92.0 %다.
  - 이득은 약 +0.5 / +0.9 pp이다.
  - 채택하지 않은 이유:
    1. 벤치마크에 없는 증거(SIMBAD, 전파, X선 등)에 쓰는 문헌 사전 가중치를 쓸 수 없다.
    2. 증거가 빠진 천체에 대한 강건성(증강)을 아직 검증하지 않았다.
    3. 기권 임계를 다시 보정해야 한다.
