## 4. 과학적 근거 (요약)
- 큰 은하 조각화: SDSS/PS1의 은하 쪼개짐(Blanton+2005), SGA-2020 D26 타원(Moustakas+2023). 같은 은하 판정의 속도 한계 1500 km/s.
- 별: Pecaut & Mamajek(2013) / Mamajek 표, Gaia GSP-Phot(Andrae+2023), 소광 계수(Casagrande & VandenBerg 2018), 거성 경계(Ciardi+2010/11), 쌍성의 주계열 위 밝기 0.75 mag(Hurley & Tout 1998), 백색왜성 위치(Gentile Fusillo+2021).
- 은하: SDSS BPT 분류(Bolton+2012; Baldwin+1981; Kauffmann+2003), 적외선 AGN(Stern+2012), WISE W2−W3(Jarrett+2017/2019), NUV−r(Kaviraj+2007), u−r 2.22(Strateva+2001).
- 퀘이사: R_i(Ivezić+2002; Kellermann+1989), 전파 스펙트럼 지수 α = −0.7(Condon 1992), z ≥ 2.1(Ross+2012).

## 5. 남은 한계와 제안
- 광도 계급에는 거성 정답 표본이 없어 정량 검증을 못 했습니다. 다음 후보는 APOGEE·Gaia FLAME 거성 표본입니다.

### 9.1 큰 은하 통합 (`v2/host_groups.py`)
| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 분류가 끝난 **뒤**(pipeline 마지막)에 묶음 | 연관(Stage 1)이나 증거(Stage 4)를 건드리면 거친 분류 벤치마크와 융합 가중치가 모두 바뀐다. 후처리로 두면 분류 결과는 그대로이고, 묶음만 추가되며, 언제든 끌 수 있다. | Stage 1에서 조각을 같은 천체로 연관: 조각의 측광이 본체 특징에 섞여 증거가 오염됨 |
| 행을 지우지 않고 `parent_object_id`·`component_role`만 붙임 | 원자료 추적성 유지, DESI 정답과의 대조처럼 조각 단위 검증이 계속 가능, 앱에서 "부분 보기"로 되살릴 수 있음 | 조각 행 삭제: 되돌릴 수 없음 |
| 묶지 않는 예외를 역할(foreground_star 등)로 남김 | 사용자가 "왜 따로 있나"를 화면에서 바로 알 수 있고, 검증 로그에서 오판을 추적하기 쉬움 | 조용히 제외 |
| 같은 은하 판정을 SIMBAD/NED 이름 또는 중심 5″로 제한 | 처음 구현(모든 이름 비교)은 본체가 이미 가진 PS1 이름과 우연히 겹쳐 오염됨(E2) | 모든 카탈로그 이름 비교 |
| 속도 한계 1500 km/s | 한 은하 안의 속도 폭(≲ 600 km/s)보다 넉넉하고 배경 천체와는 충분히 떨어짐. 묶는 쪽으로 관대하게 | 고정 거리만 사용: 배경 퀘이사가 묶임 |

| 기계학습 대신 **문헌 규칙 함수** | 세부 클래스 대부분은 정답 라벨이 없거나(운동학 집단, 적외선 초과 등) 적어 학습이 불가능. 규칙은 근거를 그대로 보여줄 수 있고(basis 문자열), 천체당 약 0.4 ms로 빠름 | 분광형 kNN/분류기 학습: 정답 체계(SDSS vs DESI)가 서로 어긋나(E8) 학습 대상 자체가 불안정 |
| 주 세부 분류 1개 + **속성 태그 여러 개** | "K형 왜성"이면서 "헤일로 별"이고 "쌍성 후보"일 수 있음: 서로 독립인 성질을 하나의 라벨에 넣으면 조합 폭발. 주 분류는 아이콘·평가 기준으로 고정하고, 태그는 자유롭게 늘림 | 모든 조합을 라벨로: 라벨 수 폭증, 평가 불가 |
| 태그마다 `rule`·`basis`(측정값) 저장 | 판정을 사람이 재검토할 수 있어야 함(과학적 근거 우선). 앱 상세 패널에 그대로 표시 | 라벨만 저장 |
| 분광 라벨 > 측광 기준 순서 | 분광 측정이 측광 추정보다 직접적인 증거 | 투표/평균 |
| 신뢰도 = 벤치마크 train split에서 **측정한 규칙 정밀도** (`subclass_rule_precision.json`) | 확률을 임의로 지어내지 않기 위함. test split은 보고용으로만 남겨 과적합 방지 | 고정 상수 신뢰도 |
| Gaia 색과 Teff 유형의 **평균** | DESI 독립 정답에서 계급 정확도 0.61 → 0.82. 한 쪽만 쓰면 금속량·소광 영향이 그대로 남음 | 색만 사용 |
| 광도에는 **분광 적색편이만** 사용 + M_B > −10 거부 | SIMBAD z(측광 섞임) 때문에 M_B ≈ −5 "왜소은하" 30개가 나옴(E12). 물리적으로 불가능한 값은 라벨 대신 버림 | 모든 z 사용 |
| 거리 계산을 numpy 적분 + `lru_cache`로 직접 구현 | 분류 경로에 astropy 의존을 추가하지 않음(앱 배포 크기·시작 시간), 같은 z 반복 계산 캐시. 표준값(z=1에서 6608 Mpc)과 일치 확인 | astropy.cosmology |
| 녹색 계곡은 평가 점수에서 제외 | SDSS 정답 체계에 해당 범주가 없음: 점수에 넣으면 정확도가 0.79 → 0.71로 왜곡 | 비활동으로 간주 |
| 은하 부분(host)에 핵 스펙트럼을 **물려준 뒤** 세부 분류 재계산 | 분류(7단계)가 통합보다 먼저 실행되므로, 통합 후 한 번 더 계산해야 핵 스펙트럼이 본체 판정에 쓰임. 전체 재계산이 1초 미만이라 부분 갱신(E3의 dtype 오류)보다 단순 | 호스트 행만 부분 갱신 |

### 9.3 평가 스크립트 (`benchmark/evaluate_subclass.py`)
- 분광 **클래스·세부 라벨은 주지 않고 적색편이만** 준다: 라벨을 주면 평가가 자기 자신을 맞히는 꼴(누수). 적색편이는 실제 영역에서도 분광이 있으면 쓰는 정보라 공정함.
- 정답이 없는 속성(운동학 집단, 준왜성, 금속 결핍)은 **물리적 일관성 검사**로 대신함: 금속량이 얇은 원반→헤일로로 감소하는지, 준왜성이 금속 결핍인지. 맞지 않으면 기준을 다시 봄.

## 10. 단위 통일 · 미분류 천체 처리 · 'from paper' (2026-10-10 밤)
요청:
- 같은 양을 받아오면 단위를 통일한다.
- 분류가 잘 안 되는 천체를 다파장 데이터와 기준으로 분류한다.
- 카탈로그로 판정이 안 되는 천체는 UNKNOWN으로 두되, 관련 논문이 있으면 'from paper'로 출처와 분류를 보여준다.

### 10.2 UNKNOWN 진단 (245/+43, 반경 3′, 699개 중 271개 UNKNOWN)
- 212개는 한 카탈로그에서만 보인다.
  - PS1만: 92개. 유효한 평균 측광이 없음(−999), 검출 2~3회.
  - LS만: 76개. r ≈ 23.3–24.2로 형태를 쓰는 기준 S/N 10 미만.
  - SDSS만: 26개. r ≈ 24.3으로 SDSS 완전도 한계 22.2보다 어두움.
  - GALEX만 6개, AllWISE만 2개.
- 이 천체들은 분류할 정보 자체가 부족하다. 기준을 낮추면 정확도만 떨어지므로 UNKNOWN으로 두고 이유를 보여준다.
- DESI faint 정답 세트의 UNKNOWN 380개는 대부분 밝은 점광원(PSF 214개)이다.
  - 별과 퀘이사가 g−r, z−W1, W1−W2에서 겹친다(중앙값 차이가 산포보다 작음).
  - 이 색들은 이미 색 kNN이 쓰고 있다. 같은 색으로 새 기준을 만들면 정확도를 내주고 커버리지만 얻는다.
  - 독립적인 정보는 Gaia 운동뿐이어서 이것만 기준으로 추가했다.

### 10.4 설계 이유 — 왜 이렇게 코드를 짰는가
| 결정 | 이유 | 버린 대안 |
|---|---|---|
| 단위 통일을 **새 열(`std_*`) 추가**로 구현, 원래 열은 그대로 | 기존 규칙·융합 가중치·벤치마크가 원래 열에 맞춰져 있음. 덮어쓰면 모두 다시 맞춰야 하고 원자료 추적도 끊김. 추가만 하면 기존 결과가 그대로 유지됨(거친 분류 지표 불변 확인) | 원래 열을 변환된 값으로 교체 |
| Gaia 등급은 변환하지 않음 | Gaia 색을 쓰는 기준(Pecaut & Mamajek, 백색왜성 궤적)이 모두 Gaia 체계로 정의됨. AB 영점은 문헌으로 확인하지 못함 | 근거가 불확실한 AB 변환 |
| WISE 색 기준은 Vega로 되돌려 적용 | Stern, Assef, Hickox 기준이 Vega로 정의됨. std(AB)에서 같은 상수를 빼서 한 원천만 사용 | 원래 열과 std 열을 섞어 사용 |
| 'from paper'는 **주 분류를 바꾸지 않음** | 요청이 "UNKNOWN으로 두고 논문을 표시"였고, 문헌 라벨이 섞이면 분류기 정확도를 측정할 수 없음. SIMBAD/NED 유형을 거친 분류 증거로 넓히는 안은 벤치마크에 SIMBAD/NED 특징이 없어 효과를 잴 수도 없었음 | SIMBAD 계층 유형을 증거로 추가 |
| 논문 순서: 단일 논문 카탈로그 → SIMBAD 유형과 대표 논문 3편 → NED 유형 | 출처가 분명한 것부터. SIMBAD는 큐레이터가 문헌에서 정한 유형이고, `obj_freq`(논문 안에서 언급된 횟수)로 "가장 많이 다룬 논문"을 고를 수 있음 | 최신 논문 순 |
| "탐지 대역만 말하는 유형"(IR, X, IrS …)에 (detection only) 표시 | "적외선원"은 무엇인지가 아니라 어디서 보였는지일 뿐. 다른 분류와 같은 무게로 보이면 오해를 부름 | 그대로 표시 |
| 논문 정보 수집을 SIMBAD 수집기 안의 TAP 한 번(300개씩)으로 처리 | 천체마다 질의하면 수백 번 왕복. 실패해도 `simbad_reference_status`만 남기고 기존 수집은 그대로 | 천체별 질의, 별도 수집기 |
| 미분류 천체는 **새 기준을 만들기 전에 진단부터** | 진단해 보니 대부분 탐사 한계 근처의 단일 검출이었음. 기준을 낮추면 정확도만 잃음(규칙 2). 그래서 분류 대신 이유를 보여줌 | 기준(임계값) 완화 |
| Gaia 10σ 규칙은 융합 가중치를 바꾸지 않고 **판정 단계의 예외**로 넣음 | 물리적으로 결정적인 증거라 확률 모형에 맡길 이유가 없음. 가중치를 다시 학습하면 다른 클래스까지 영향을 받음. 기준값 10σ는 오차 과소추정(×1.5)에도 버팀 | 운동 증거의 점수 상한 상향 후 재학습 |
| 이 규칙의 신뢰도 = 벤치마크에서 측정한 정밀도(0.99) | 강제로 정한 라벨에 다른 클래스의 확률을 신뢰도로 붙이면 오해를 부름. 측정값을 그대로 사용 | 융합 확률 그대로 |
| 미분류 이유를 세부 분류 단계(`annotate`)에서 계산 | 이 단계에 상태·확률·증거·std 등급이 모두 모여 있고, 큰 은하 통합 뒤 다시 실행되므로 최종 상태와 어긋나지 않음 | 05 단계에서 계산: std 등급과 큰 은하 통합 결과가 없음 |

### 10.5 남은 한계
- SIMBAD 논문 정보(TAP)는 아직 실제 영역 로그로 확인하지 못했다. 245/+43에는 SIMBAD 천체가 14개뿐이다.
