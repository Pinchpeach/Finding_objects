## 4. 설계 이유
- **C* 게이트를 4단계 증거에 붙이고 5단계에서 쓰는 방식**: 5단계는 증거 목록만 보므로, 원자료 열을 5단계로 넘기는 대신 증거 항목에 `cstar_sigma`를 기록했다. 증거 점수 자체는 바꾸지 않아 학습된 융합 가중치가 그대로 유효하다. 바뀌는 것은 "규칙으로 덮어쓰기"(결정적 운동, 은하 안 예외)뿐이다. 문턱 5σ는 기존 WD 게이트(`plx4_cstar5`)와 같고, Riello+2021의 고립 점광원 산포를 기준으로 한다. 대안(DSC 은하 확률 > 0.5로 막기)은 2.16.0에서 DSC 사전확률을 나눈 뒤 DSC 값이 덜 직접적이라 버렸다.
- **SIMBAD 계층을 표로 가지고 다님**: 실행 때마다 SIMBAD에 묻지 않고 226줄 CSV를 앱에 함께 넣는다. 네트워크 없이도 같은 결과를 내고 속도 영향이 없다(lru_cache). 후보 코드(`?`)는 큐레이션된 분류가 아니라 판정에 쓰지 않는다.
- **DSC 재학습을 버린 이유**: 같은 학습 절차로 DSC를 넣어 다시 맞추면 SDSS −0.25 %p, DESI −0.84 %p였다. 부호 제약에서 DSC 키가 빠졌고, 사전확률 나눔(Delchambre+2023 권고, 2.16.0)이 SDSS의 클래스 구성과 맞지 않기 때문으로 보인다. 정확도를 희생하지 않도록 기존 가중치를 유지하고, 숫자는 DSC를 포함한 정직한 값(97.59 %)으로 보고한다.
- **준왜성은 시차 선택만**: Culpan+2022의 고유운동 선택은 완전도 50 %·오염 28 %라 정확도 원칙에 맞지 않는다. 시차 선택은 완전도 80–90 %·오염 ~10 %. 우리 측정(84.8 %, 81 %)이 논문 범위와 맞다. 5″ 혼잡 필터는 주변 Gaia 천체 전체가 필요해 생략하고, 대신 C* < 0.6이 혼합 측광을 거른다.
- **준왜성 판정 위치**: 별 가지(WD 판정) 앞에 둔다. 영역이 겹치지 않고(WD는 G_abs > 7), 이전에는 이 별들이 "주계열 아래 → VI 준왜성" 또는 무판정이었다.
- **초저온 왜성은 Gaia ESP-UCD만**: Gaia가 RP 스펙트럼으로 이미 Teff를 냈으므로 색 규칙(PS1·WISE)을 새로 만드는 것보다 정확하고 빠르다. 갈색왜성/초저질량 별 구분은 나이가 필요해 주장하지 않는다.
- **YSO는 재분류만**: 이미 수집하는 Gaia 변광 클래스를 OTHER_VARIABLE에서 따로 떼어냈다. 문헌 오염률(~10 %)이 다른 Gaia 변광 클래스와 비슷하다. WISE 색 규칙은 우리 깊이에서 오염률을 잴 독립 정답이 없어 넣지 않았다.
- **블레이자는 목록 일치**: BZCAT는 모든 원천이 전파 검출 + 광학 스펙트럼으로 확인된 목록이라 ATNF와 같은 신원 증거로 쓴다. WISE 블레이자 띠 규칙은 BZCAT로 검증할 수 있지만 거기서 순도를 재려면 영역 단위 검증이 필요해 다음으로 미뤘다.
- **README 문체**: 보낸 노트는 날짜와 `[번호] 제목`으로 단원을 나누고, `ㄴ`로 하위 내용을, `★`로 중요한 정리를, `ex)`로 예를, `→`로 결과를 쓴다. 독후감은 "~다"로 끝나는 담백한 평서문이다. README는 이 두 가지를 합쳐 다시 썼다. 문서의 개인 정보(소속·계급·이름)는 넣지 않았다.
- **MIT 라이선스**: 의존 패키지(NumPy·pandas·Astropy·astroquery·PyVO: BSD, Requests: Apache-2.0)와 모두 호환되고 가장 단순하다. Qt/PySide6(LGPLv3)은 앱이 수정 없이 별도 공유 라이브러리로 동적 연결하므로(PyInstaller one-folder) MIT 코드와 함께 배포할 수 있다. 이를 위해 라이선스 원문 위치와 소스 링크를 `THIRD_PARTY_NOTICES.md`에 적고, 두 파일을 앱 번들에도 넣었다. 저작권자는 git 기록의 저장소 소유자(Choi Jiung), 연도는 첫 커밋 연도(2026). GPL 계열은 사용자가 결과를 연구에 자유롭게 쓰는 데 불필요한 제약이라 고르지 않았다.

## 5. 보류한 대상과 이유
| 대상 | 이유 |
|---|---|
| X선 쌍성(XRBcats) | 목록 조회만 가능하고 독립 정답이 없음. SIMBAD XB*·LXB·HXB 경로가 이미 있음 |
| 격변 변광성 | Gaia CV → ERUPTIVE가 이미 있음. 준왜성·WD와 HR 영역이 겹쳐 두 작업 뒤에 Ritter & Kolb로 검증하는 것이 맞음 |
| 볼프-레이에 별 | 측광 경로가 Gaia ESP-ELS뿐인데 2.6.2에서 SIMBAD 일치 2–30 %로 측정됨 |
| 은하단 | 한 천체가 아니라 여러 천체의 묶음. 새 단위(host_groups 같은 구조)가 필요 |
| E+A 은하 | Hδ·[O II]를 수집하지 않음. SDSS 분광에만 해당 |
| 공생별·초고속 별·중력렌즈 퀘이사 | 영역 하나에 거의 없음. 초고속 별은 시선속도·탈출속도 모형이 필요하고, 헤일로 표지가 이미 쓸모 있는 부분을 담음 |
