# 예측 (변형을 구현·실행하기 전에 씀, 2026-11-28; 과제 너)

**배경 (이미 잰 것)**: `V2_POSERR_NATIVE=allwise`(AllWISE `eeMaj`를 위치 오차로 읽음)는 깊은 COSMOS 26개 영역에서 올바른 연결 7,282 → 7,660(+378, +5.2 %), 틀린 연결률 2.08 % 그대로, 누락 13.25 → 12.81 %, 2′ 이동 대조의 거짓률 7.63 → 8.31 %(+0.68 %p), AllWISE가 앵커인 객체 3,728 → 3,341, 객체가 달라진 것 393개다. 연결 반경에 쓰는 σ는 PSF/6 하한(AllWISE 1.017″) 때문에 거의 그대로이므로 효과는 **처리 순서 키**(`_anchor_key`가 하한 없는 `poserr_arcsec`를 씀)에서 온다는 것이 가설이다.
`base`의 AllWISE `poserr_arcsec`는 행마다 같은 가정값(0.5″)이고, `eeMaj`의 중앙값은 0.34″다. LS 해상 모델 행은 0.6″ 하한이 63 %다. 그래서 `eeMaj > 0.5–0.6″`인 AllWISE 행은 순서에서 광학 행 뒤로 밀려 앵커가 되는 대신 광학 객체에 붙고, 그것이 조각을 줄인다는 것이 가설이다.

**새 변형** (모두 기본 꺼짐):
* `V2_POSERR_NATIVE=allwise_order`: `eeMaj`는 순서 키에만 쓰고 σ(연결 반경·점수)는 base 값.
* `V2_POSERR_NATIVE=allwise_sigma`: `eeMaj`는 σ에만 쓰고 순서 키는 base 값.
* `V2_ASSOC_ORDER_KEY=floored`: 순서 키가 하한을 적용한 σ(`effective_sigma_arcsec`, PSF/6 하한, 이동 보정 없음)를 쓴다. 모든 카탈로그에 해당(2MASS 0.25″ 대 하한 0.42″, GALEX 하한 0.883″ 포함). `allwise_order`와 같이 쓰면 `eeMaj`에 하한을 씌운 값이 키다.
