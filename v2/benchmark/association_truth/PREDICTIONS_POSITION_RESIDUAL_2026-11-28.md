# 예측 (잔차 분석을 돌리기 전에 씀, 2026-11-28; 과제 너 추가: 객체 위치가 정답에서 얼마나 먼가)

배경: (d)의 2.61.0 순서 비교에서 "새 순서"가 `exists` 읽기의 보정 반쪽을 −36(p 0.009)으로 바꿨고 깨진 108개 중 105개가 "0.5″ 안에 객체가 없어짐"이었다. 클래스가 아니라 객체 위치(앵커 위치)가 정답에서 멀어지는 효과일 수 있다는 지적(계획 세션 02:33). 이것을 정답(COSMOS2020)에 대한 **객체 위치 잔차**로 직접 잰다.

정의(실행 전에 정함): 객체 = 1단계의 그룹, 위치 = `object_ra/object_dec`. 정답에 닿는 객체 = 해상 카탈로그(`measure_association.RESOLVING`)의 행이 HSC i < 25 정답 원천의 0.6″ 안에 있고, 그 객체의 정답 id가 **하나**인 것. 잔차 = 객체 위치와 그 정답 원천 위치의 거리. 요약: 중앙값, 90·99 백분위, 0.3·0.5·0.7·1.0″ 밖 비율, 등급(HSC i: <20, 20–22, 22–24, 24–25)과 앵커 카탈로그별. 같은 정답 원천에 대한 쌍 비교(두 변형 모두에서 단독 보유 객체가 있는 원천)로 변형의 차이를 본다. 변형: `new`(기본 동점 순서 = 밝기, 2.61.0 이후), `file`(2.60.x의 순서: 같은 키면 입력 파일 행), `position`, `floored`, `allwise_order`. 출력 위치 설계 3가지(같은 그룹, 위치만 다름): 현재(앵커), **가장 정밀한 구성원**(`effective_sigma_arcsec` 최소), **역분산 가중 평균**(해상 구성원만).

| # | 예측 | 틀렸다고 볼 기준 |
|---|---|---|
| R1 | `new` 순서의 잔차: 중앙값 0.05–0.15″, 90 백분위 0.2–0.5″, 99 백분위 0.8–2.5″, 0.5″ 밖 3–8 % | 중앙값이 0.2″ 넘거나 0.5″ 밖이 10 % 넘으면 |
| R2 | `file`과 `new`의 차이는 작지만 **부호가 있다**: `new`의 0.5″ 밖 비율이 `file`보다 0.1–0.8 %p 크고(검토가 본 "0.5″ 안에 객체 없어짐"과 같은 방향), 중앙값 차이는 0.01″ 미만 | `new`가 `file`보다 낫거나(0.5″ 밖 비율이 같거나 작음), 차이가 1 %p 넘으면 |
| R3 | 쌍 비교에서 `new`가 `file`보다 나빠진 원천(잔차가 0.1″ 넘게 커짐)이 좋아진 원천보다 많다. 나빠진 원천의 주된 앵커 전환은 LS ↔ PS1 또는 PS1/LS ↔ AllWISE이다 | 나빠진 수가 좋아진 수 이하면 틀림 |
| R4 | `floored`는 `new`와 잔차 분포가 거의 같다(중앙값 차이 0.01″ 미만, 0.5″ 밖 비율 차이 0.3 %p 이내). AllWISE가 앵커이던 객체가 61 % 줄어(26개 영역 합) 그 객체들의 큰 잔차가 사라지는 효과가 있어도 전체 비율에 거의 안 보인다 | 0.5″ 밖 비율 차이가 0.5 %p 넘으면 |
| R5 | AllWISE·GALEX가 앵커인 객체의 잔차는 광학이 앵커인 것보다 크다(AllWISE 앵커 중앙값 ≥ 0.4″) | AllWISE 앵커 중앙값이 0.25″ 미만이면 |
| R6 | 출력 위치를 "가장 정밀한 구성원"으로 하면 `new`의 0.5″ 밖 비율이 **20 % 이상(상대) 줄고**, 역분산 가중 평균은 그것과 비슷하거나 약간 더 낮다. 중앙값은 5–15 % 줄어든다 | 0.5″ 밖 비율이 10 % 미만으로 줄면(앵커 위치가 이미 가장 정밀) 틀림 |
