# 예측 (변형을 구현·실행하기 **전에** 쓴 것) — 문헌 전용 객체와 AllWISE/GALEX 오차 열 (2.62.4 계획)

git 순서: 이 파일과 기준 진단(`literature_only.py`, `results_2026-11-28/literature_only_objects_base_cosmos.csv.gz`)이 먼저, 스위치 구현과 변형 측정은 그 뒤 커밋이다.
기준 진단은 현재 코드(변형 없음)의 상태를 센 것이라 변형의 결과를 포함하지 않는다.

## 0. 이미 센 것 (기준 상태, 실사용 COSMOS 2′ 한 영역)

* 3,572개 그룹 중 **문헌 전용(NED·SIMBAD 행만) 2,544개**(71 %). NED·SIMBAD 행이 저장된 영역은 이 영역과 NGC 4522(SIMBAD 1행)뿐이라, 문헌 전용 객체를 재볼 수 있는 곳은 사실상 이 한 영역이다. 저위도·깊은 COSMOS 26개는 블라인드(NED·SIMBAD 없음).
* 가장 가까운 광학(탐사) 객체까지의 거리: ≤0.5″ 175, 0.5–1″ 77, 1–2″ 409, 2–5″ 1,467, >5″ 416. 위치를 문헌 객체 둘레 15–40″로 무작위 이동한 대조군(200회)의 기대값: ≤0.5″ 38, ≤1″ 153, ≤2″ 561, ≤3″ 1,058, ≤5″ 1,823.
  1–2″ 구간은 관측 409 대 기대 408로 **무작위 이웃 수와 같다**(0.5″ 안쪽만 초과 137).
* 현재 규칙이 붙이지 않는 이유(가장 가까운 광학 객체 기준, 먼저 걸리는 것): 매칭 반경 밖 901, 우연 일치 확률 > 0.25 1,362(그중 광학 탐사 밀도만 쓰면 통과 694), 같은 카탈로그의 typed 행이 이미 있어 막힘 281. `typed_block`을 따로 세면 1,818(대부분 SIMBAD `G`).
* 반경 안에서 **우연 일치 문턱만 풀면** 새로 붙는 후보 208(1–2″ 96, 2–3″ 104, 3–6″ 8), **typed 규칙만 0.6″ 안에서 풀면** 187.
* 문헌 QSO 라벨 16개(서로 다른 위치 12개; NED 행이 둘로 갈라진 쌍이 4개): 반경 밖 7, 우연 일치 8, typed 1(이유 사슬 기준). `typed_block` 열로는 **16개 중 12개가 typed 규칙에도 걸린다**; 우연 일치 문턱만 풀면 붙는 것은 OBJ001195 하나뿐.
* 좌표 오차: SIMBAD 3,226행 중 `coo_err_maj`가 채워진 것은 19행(0.6 %), `coo_qual`은 수집하지 않음. NED 행에는 오차 열이 없음. 그래서 문헌 행의 오차는 모두 기본값 0.6″.
* AllWISE는 저장된 `eeMaj`(중앙값 0.34″)를 읽지 않고 상수 0.5″, GALEX는 `Nerr`/`Ferr`(중앙값 1.5″/1.3″)를 읽지 않고 상수 0.8″. 다만 `effective_sigma_arcsec = max(poserr, 0.02, PSF/6)`이라 AllWISE는 1.02″, GALEX는 0.88″ 하한이 이미 걸려 있다.
* 2.60.9 경험적 오차 모형(26개 영역, COSMOS2020 기준): AllWISE 고립 원천의 핵 σ 0.38″(모형 1.02″의 0.37배), 블렌드 1.24″(1.22배); GALEX 고립 1.18″(1.33배), 블렌드 2.44″(2.74배).
* 기준 거짓·누락(`association_truth/results_2026-11-25/false_missed_base.csv`, 26개 영역): AllWISE 거짓 2.08 %·누락 13.7 %(기대 대비)·이동 대조 거짓 7.6 %; GALEX 거짓 6.23 %·누락 21.95 %·이동 대조 거짓 30.2 %.

## 1. 구현할 스위치 (모두 기본 꺼짐, 켜지 않으면 비트 단위로 같다)

| 환경변수 | 값 | 하는 일 |
|---|---|---|
| `V2_ANNOT_ASSOC` | `density` | NED·SIMBAD 행이 광학 객체에 붙는지 볼 때 우연 일치 확률의 밀도를 **광학 객체(후보 카탈로그) 밀도만**으로 계산(지금은 두 카탈로그 중 큰 쪽) |
| | `typed_close` | 같은 카탈로그의 typed 행이 있어도 **0.6″ 안**이면 같은 객체로 본다(0.6″ = COSMOS2020의 부속 카탈로그 매칭 반경, Weaver+2022 §2.6) |
| | `err` | SIMBAD `coo_err_maj`(단위는 원문 확인 후)가 있으면 그것을 위치 오차로 읽는다 |
| `V2_POSERR_NATIVE` | `allwise` / `galex` | AllWISE `eeMaj`, GALEX `Nerr`(없으면 `Ferr`)를 위치 오차로 읽는다(PSF/6 하한은 그대로) |
| | `allwise_raw` | 위와 같되 AllWISE에만 PSF/6 하한을 걷는다(σ = eeMaj) |

NED·SIMBAD가 없는 영역에는 `V2_ANNOT_ASSOC`이 닿는 행이 없다. (NED·SIMBAD 행에만 적용하도록 한정한다. 다른 주석 카탈로그인 Galaxy Zoo DESI, Roma-BZCAT 등에는 적용하지 않는다.)

## 2. 평가 정의 (결과를 보기 전에 정함)

* **다리 정답**(실사용 COSMOS 2′): COSMOS2020(`deep_cosmos_5` 기준 표) 중 HSC i < 25 원천 집합 R. 문헌 행과 광학 객체는 각각 R에서 0.6″ 안 가장 가까운 원천을 자기 id로 갖는다. 새로 붙은 쌍은 **맞음**(두 id가 같음) / **틀림**(둘 다 있고 다름) / **모름**(어느 한쪽이 R에 없음)으로 센다. (`measure_association.py`의 ID_RADIUS 0.6″, REF_MAG 25.)
* **유형 대조**(손 확인의 대용): 새로 붙은 문헌 행의 유형(NED `Type`, SIMBAD `otype`)을 붙은 객체의 분류와 비교(예: 문헌 `*`/`PN` 등이 은하 객체에 붙음).
* AllWISE·GALEX: `measure_association.py`의 거짓(정답이 알려진 연결 중 틀린 비율)·누락(기대 짝이 있는데 못 붙은 비율)·이동 대조 거짓(2.49.0 정의), 보정/시험 분할을 따로 보고 영역 부트스트랩 구간을 함께.
* 블라인드 불변: 26개 깊은 COSMOS 영역(문헌 행 없음)에서 모든 스위치 켠 상태의 `source_association.csv`가 기준과 **같다**.

| # | 변형 | 예측 |
|---|---|---|
| B1 | `allwise` (하한 유지) | eeMaj가 PSF/6 하한 1.02″ 이하인 행이 거의 전부(저장된 분포 q90 0.58″)라 σ가 사실상 안 바뀐다 → 연관이 기준과 **거의 같다**(바뀌는 AllWISE 행 1 % 미만, 거짓·누락 차이 ±0.1 %p 이내) |
